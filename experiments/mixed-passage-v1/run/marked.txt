Set the reference flow to 40 litres per minute before you record the first reading on the raw sheet. Maintain the line at that rate for two minutes so the pressure can settle. Write down the meter value, the ambient temperature, and the clock time. Take readings at 60 and 80 litres per minute, and allow the same settling time at each setting. If a value changes by more than 2 per cent across repeats, stop the run and examine the coupling for leaks before you resume. A minor leak at the union will bias every later reading, so completing the check before proceeding is worthwhile despite the delay. Note the serial number of the reference meter and the date of its last calibration on the raw sheet. If that date falls outside the preceding twelve-month window, treat the run as invalid and obtain a reference meter with calibration dated within that period before proceeding. Keep the raw sheet even when a run is void, because the sheet still shows what the instrument was doing at that time. When measurements at all three rates are complete, work out the mean error at each point and plot it against the permitted range. A meter whose error lies inside the band at every point passes the verification. A meter whose error falls outside the band at any single point fails the whole verification, and no mean across the three rates can alter that outcome. Sign the sheet, state the ambient conditions, and send the signed result to the quality file. Where a run is stopped early, write the reason on the sheet in plain words, because a blank field tells the next reader nothing at all. Store the sheets in date sequence so that a later query can be answered using those records. If the meter is moved to another bay, note the new location and the date of the move, because a meter that has moved may need a further check before its next use. Report any damage or faults affecting the reference equipment on the same day, and do not proceed with a run on equipment you cannot trust. A doubtful reference makes every reading obtained with it doubtful too, and the cost of repeating a run is lower than the cost of correcting a bad result. When the file is complete for the month, check that every sheet has a signature and that no run is missing from the sequence. A gap in the record is harder to explain later than a poor result recorded accurately at the time.
